# Points Rules — 自定义积分规则

- 自定义业务的人民币与积分兑换基准：**1 RMB（人民币1元）= 1,000积分**。金额转积分：`points = amountRMB × 1000`；积分对应的人民币参考金额：`amountRMB = points ÷ 1000`。例如：¥29 对应29,000基础积分。
- 消费金额转换为消耗积分时使用**进一法（向上取整）**：`consumedPoints = ceil(consumedAmountRMB × 1000)`。积分最小单位为**1积分**，消耗积分必须是整数；正数消费不足1积分时按1积分计，零消费为0积分，恰好为整数时不额外加1。例如：¥0.0001 → 1积分，¥0.001 → 1积分，¥0.0011 → 2积分。换算应使用精确十进制运算，避免二进制浮点误差导致多扣1积分；该规则仅定义消费金额换算，不扩展为充值、赠送或退款的取整规则。
- 订阅、钱包、价格展示及相关文档采用该基准；优惠或赠送积分单独计算、单独说明，不将包含赠送的到账总积分反推为实际支付金额，也不据此承诺积分可提现。
- 业务积分与 new-api 底层整数 `quota` 是不同概念。此规则不定义 `points ↔ quota` 映射，不修改 `QuotaPerUnit` 或美元计价逻辑；涉及真实扣费、充值、结算或存量数据转换时，先核实已有单位、币种与换算链路，不能直接把积分当作 quota。
- 本条是业务约定，不表示该比例已经在所有现有后端功能中实现；消费金额转积分遵循上述进一法；其他场景的金额精度与取整方式须遵循对应业务的明确契约，不能由兑换比例自行推断。
