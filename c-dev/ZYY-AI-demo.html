订阅规则

  1. 月付价格：¥29 / ¥89 / ¥199

    对应常规积分分别为 29,000 / 89,000 / 199,000，每期服务期为1个月。入门档提供精选稳定模型、接入文档与常见问题、标准支持；标准档提供新模型成熟后开放、接入问题排查协助、优先支持；专业档提供新模型优先体验、复杂接入与配置协助、高优先级支持。月付与年付同档权益一致。

  2. 年付价格：¥290 / ¥890 / ¥1,990

    对应常规积分分别为 348,000 / 1,068,000 / 2,388,000，服务期为12个月；较逐月购买省2个月费用，积分支付成功后一次到账。

  3. 购买方式：单次购买或自动续费

    同档同周期的价格相同；单次购买不会新增自动续费授权。已存在的同档同周期授权不会因单次购买自动取消。

  4. 自动续费：确认授权后按期扣款

    开通后，将按确认的档位、周期和支付方式自动续费。已购方案单独开通授权时，不立即扣款、不发积分。

  5. 额外赠10%：仅实际自动续费成功才发

    赠送基数为同档同周期常规积分总额。首次购买、仅开通授权、扣款失败均不赠送。

  6. 取消自动续费：只停止后续扣款

    可在对应卡片开关或自动续费管理取消，已购买服务期、已到账积分不受影响。

  7. 自动续费设置：同时只保留一个方案

    重新授权其他档位或周期会替换原设置；请核对确认弹窗中的周期、金额和支付方式。

  8. 同档续订：延长服务期

    再次购买相同档位，积分支付后到账，服务期从原到期日顺延。相同周期的自动续费授权保留，预计扣款时间随服务期顺延。

  9. 升级：高档立即生效，低档剩余时长保留

    按新高档周期完整购买，不按差价折算；原低档未用完的服务时长暂停，后续按权益排期恢复。

  10. 降级：先获得积分，服务权益排期

    支付成功后新订单积分即时到账；低档服务在当前及前序保留权益结束后生效，不立即替换当前高档权益。

  11. 切换方案或周期：重新核对自动续费

    手动购买不同档位或周期会取消旧自动续费设置；需要继续自动续费时，须重新确认授权。

配置教程

从创建密钥到接入工具，按目录找到所需说明。所有步骤、代码示例和常见报错均在本页展开，可使用浏览器查找（Ctrl / ⌘ + F）定位关键词。

使用流程

与「首页 → 常用 → 新手引导」一致，按「创建密钥 → 准备积分 → 接入我的应用」准备使用。已有可用密钥和足够积分时，无需重复创建或订阅。准备好密钥和积分后，手动进入第 3 步复制接入信息，在自己的应用中验证真实调用。首次进入从第 1 步开始，不自动跳步；三步均可回看，返回不会清空密钥或订阅数据。

首次进入首页默认展示新手引导；可点击「稍后再看」，或在第 3 步点击「结束引导，进入API 密钥」。此后进入首页时默认打开「API 密钥」，不代表已接入成功。随时可从「首页 → 常用 → 新手引导」回看，步骤不重置。日常接入无需重走引导：进入「首页 → 常用 → API 密钥」，在对应密钥行点击「接入配置」，即可查看同一套地址、模型、密钥和代码示例。

首页左侧菜单分为「常用 / 个人 / 系统」三组。常用包含新手引导、API 密钥、使用日志、任务日志、数据看板；个人包含积分钱包、我的订阅、个人资料；系统包含安全与访问、审计日志。手机端先点击正文上方的当前页面菜单按钮展开，选择后自动收起。积分钱包展示已到账积分总额、通用积分、GPT系列专项积分及GPT系列专项积分待释放。总额为已到账未使用的通用积分与GPT系列专项积分之和，待释放奖励到账后再计入总额；历史通用奖励计入通用积分，未发放奖励资格不计积分余额。GPT系列调用先用通用积分，再用GPT专项积分；其他模型调用使用通用积分。积分明细区分通用订阅、GPT系列专项已到账与待释放，有历史通用奖励时单独展示；点击积分明细右上角「查看更多」，查看完整的积分到账、调用消耗及奖励变动记录，支持按日期筛选。钱包与邀请页常显关键说明，完整规则点击展开；本教程保留全文便于查阅。点击顶部「订阅」选购并查看订阅订单；任务页可从页面上方返回来源页。只有主动点击顶部导航才切换模块；可在顶层「订阅」的档位卡片查看价格并单次购买，在「自动续费管理」开通或取消。首次实际自动续费扣款成功起额外赠10%，首次购买不赠。

本教程无需登录即可完整阅读，不检查你的账号进度，也不会替你执行创建、订阅或调用。

1. 创建密钥

  1. 在「首页 → 常用 → 新手引导」第 1 步点击「创建 API 密钥」（已有密钥时为「创建新密钥」），在弹窗中选择模型、填写名称并创建。复制保存后点击「我已保存」，仍停留在第 1 步并提示密钥已准备好，点击「下一步」才进入第 2 步；不会自动跳步，也不会跳到「API 密钥」。已有可用密钥可直接点击「下一步」复用，无需重复创建。在「模型」点击「使用此模型」会保留选择，登录后直接进入创建表单；日常创建可进入「首页 → 常用 → API 密钥」点击「创建密钥」；管理已有密钥则在对应密钥行点击行内按钮。
  2. 每个密钥绑定一个模型。接入工具时，模型名必须与该密钥绑定的模型 ID 一致；不要用「模型」中的展示名称代替模型 ID。
  3. 密钥默认打码，可通过复制按钮取得完整密钥。不要把密钥 ID 或打码后的文字填入工具，也不要公开分享完整密钥。

已有密钥但无法调用：在「首页 → 常用 → API 密钥」找到对应密钥行，检查状态、绑定模型及密钥额度；修改时点击该行「编辑」修改名称、模型与额度。停用的密钥可点该行「启用」恢复。密钥额度上限与账号积分是两项独立限制。

2. 准备积分

  1. 在首页查看可用积分，待释放奖励不计入可用。首次使用可点击顶部「订阅」，也可从新手引导打开订阅方案任务页；任务页保留当前顶部 tab，点击上方来源返回入口继续原流程。按积分额度选择方案；月付与年付同页展示，支付方式在订单确认时选择。
  2. 月付 ¥29 / ¥89 / ¥199；年付 ¥290 / ¥890 / ¥1,990。月付获得29,000 / 89,000 / 199,000积分；年付获得348,000 / 1,068,000 / 2,388,000积分，较逐月购买省2个月费用。积分一次到账、永久有效。
  3. 同档续订延长权益，升级暂停保留低档时长，降级排期。自动续费需主动授权，首次实际自动续费扣款成功起额外赠10%；可在「订阅 → 自动续费管理」取消。权益到期后，已到账积分继续保留。
  4. 邀请奖励为GPT系列专项积分，可用于GPT系列模型调用。当前最高10%活动，按支付时已确认的有效好友人数计算：0—2人5%、3—8人7%、9人及以上10%，满7×24小时整笔到账。好友首笔有效订阅满7天且未全额退款后计入人数；复购按新订单支付时档位计算，人数跨活动保留。升级后新订单享更高比例，此前订单仍按支付时比例结算，历史订单沿用原规则。
  5. 订阅订单在订阅方案页查看；无免费试用、无注册赠分。积分不足调用前拦截，不透支。

3. 接入应用

首次接入：进入「首页 → 常用 → 新手引导」第 3 步。日常接入：进入「首页 → 常用 → API 密钥」，在对应密钥行点击「接入配置」。两处复用相同配置区，仅展示接口地址、模型名称、API 密钥（切换与复制）及「代码预配置示例」。切换 API 密钥时，模型名称和示例同步更新。逐项复制到自己的应用；密钥默认打码，复制得到完整值。代码示例按需展开，使用 YOUR_API_KEY 占位符，需替换为完整密钥。保存后在自己的应用中发送消息验证；复制配置不代表接入成功。

验证是否接入成功

常见报错

        
认证失败 / 401
检查完整密钥是否复制正确、有无空格、是否停用或已删除；不要填写密钥 ID 或打码文字。检查路径：「首页 → 常用 → API 密钥 → 对应密钥行」。停用时点该行「启用」恢复；已删除的密钥不可继续使用，须创建新密钥并更新工具配置。

        
路径不存在 / 404
区分基础地址和完整请求路径，排除重复拼接 /v1；再根据返回信息判断模型不存在或接口能力不支持，不能机械添加或删除路径。

        
模型不存在 / 不允许此密钥调用
填写与密钥绑定一致的模型 ID，保留完整大小写和后缀。模型已下架时，进入「首页 → 常用 → API 密钥」，在对应密钥行点「编辑」更换绑定模型，或点击「创建密钥」新建；完成后重新打开「接入配置」，同步更新工具中的模型 ID 和密钥。

        
积分不足 / 密钥额度不足
账号积分不足：在「首页 → 个人 → 积分钱包」检查余额，必要时进入顶部「订阅」选择套餐；通用积分适用于所有已开放模型，GPT系列专项积分用于GPT系列模型调用；请按当前所选模型核对可用积分。密钥额度耗尽：进入「首页 → 常用 → API 密钥」，在对应密钥行点「编辑」调整积分上限，保存后密钥自动恢复启用。仅购买订阅不能解决密钥上限限制，仅提高密钥额度也不会增加账号积分。

        
限流 / 429、超时或服务错误
遵循返回的重试指引或 Retry-After，降低并发，避免无限重试；超时先检查网络和服务状态。不要一律关闭代理或绕过组织安全策略。仍失败时记录请求时间、请求 ID 和错误信息。

      

      
积分
  1. 积分使用：通用优先，专项用于GPT系列
    订阅及其赠送为通用积分，适用于所有已开放模型；邀请奖励为GPT系列专项积分，用于GPT系列模型调用。调用时优先使用通用积分，再使用适配当前GPT模型的专项积分。历史已到账余额保留原使用范围。
  2. 到账时间：订阅支付成功即到账
    月付与年付积分均一次到账；自动续费额外10%只在实际自动扣款成功后到账。
  3. 有效期：已到账积分永久有效
    订阅到期或取消自动续费，不会自动清空已到账余额。
  4. 消费用途：按实际token用量扣减
    按所选模型及实际输入、输出token用量计算积分。页面展示的调用次数为参考值，不代表保证次数。
  5. 计量规则：四舍五入，单次最低1积分
    输入、输出用量分别计费后合计，四舍五入为整数积分。人民币参考费用仅用于对照，不是可提现余额。
  6. 积分不足：不透支、不扣部分积分
    调用前按所选模型核对可用积分；GPT系列可使用通用与GPT专项，其他模型使用通用积分。余额不足时先补充积分再调用，本次不会扣减部分积分。
  7. 密钥额度：不等于账号积分
    账号有积分仍可能受密钥额度上限限制；提高密钥额度不增加积分，购买订阅也不自动提高密钥额度。


订阅
积分余额与订阅服务分别管理：积分支付后一次到账、永久有效；月付服务期为1个月，年付为12个月，服务生效与到期时间见「我的订阅与权益排期」。订阅到期或取消自动续费，已到账积分仍可按适用范围使用。套餐卡先展示本次价格与到账积分，再展示后续实际自动续费的额外赠送；仅开通授权时不立即扣款、不发放积分。
  1. 月付价格：¥29 / ¥89 / ¥199
    对应常规积分分别为 29,000 / 89,000 / 199,000，每期服务期为1个月。入门档提供精选稳定模型、接入文档与常见问题、标准支持；标准档提供新模型成熟后开放、接入问题排查协助、优先支持；专业档提供新模型优先体验、复杂接入与配置协助、高优先级支持。月付与年付同档权益一致。
  2. 年付价格：¥290 / ¥890 / ¥1,990
    对应常规积分分别为 348,000 / 1,068,000 / 2,388,000，服务期为12个月；较逐月购买省2个月费用，积分支付成功后一次到账。
  3. 购买方式：单次购买或自动续费
    同档同周期的价格相同；单次购买不会新增自动续费授权。已存在的同档同周期授权不会因单次购买自动取消。
  4. 自动续费：确认授权后按期扣款
    开通后，将按确认的档位、周期和支付方式自动续费。已购方案单独开通授权时，不立即扣款、不发积分。
  5. 额外赠10%：仅实际自动续费成功才发
    赠送基数为同档同周期常规积分总额。首次购买、仅开通授权、扣款失败均不赠送。
  6. 取消自动续费：只停止后续扣款
    可在对应卡片开关或自动续费管理取消，已购买服务期、已到账积分不受影响。
  7. 自动续费设置：同时只保留一个方案
    重新授权其他档位或周期会替换原设置；请核对确认弹窗中的周期、金额和支付方式。
  8. 同档续订：延长服务期
    再次购买相同档位，积分支付后到账，服务期从原到期日顺延。相同周期的自动续费授权保留，预计扣款时间随服务期顺延。
  9. 升级：高档立即生效，低档剩余时长保留
    按新高档周期完整购买，不按差价折算；原低档未用完的服务时长暂停，后续按权益排期恢复。
  10. 降级：先获得积分，服务权益排期
    支付成功后新订单积分即时到账；低档服务在当前及前序保留权益结束后生效，不立即替换当前高档权益。
  11. 切换方案或周期：重新核对自动续费
    手动购买不同档位或周期会取消旧自动续费设置；需要继续自动续费时，须重新确认授权。


邀请好友
  1. 活动奖励：支付时锁定一个比例
    新订单按好友有效实付、支付时已确认的有效好友人数及活动比例折算为GPT系列专项积分，可用于GPT系列模型调用；满7×24小时后整笔释放，无需好友先消费。每笔订单采用一个比例，一次发放。
  2. 有效好友：同一位好友只计一次
    独立直接好友的首笔有效订阅满7天且未全额退款后确认，复购不重复增加人数；累计人数跨月、跨活动保留。
  3. 当前档位：5% / 7% / 10%
    当前活动最高10%：支付时累计0—2位有效好友为5%，3—8位为7%，9位及以上为10%。三个档位随活动最高比例按50% / 70% / 100%设置，具体以活动公布为准。
  4. 人数升级：新订单享更高奖励
    第3位、第9位好友确认有效后，提高之后支付的新订单比例；此前订单继续按支付时的金额与比例结算。例如第3位好友的首单支付时仅有2位有效好友，该单按5%计算；待其满7天计入人数，之后支付的新订单按7%计算，第9位同理。实付100元，三个档位分别奖励5,000 / 7,000 / 10,000 GPT系列专项积分。
  5. 好友复购：按新订单支付时档位计算
    购买或续订均按该笔订单支付时的活动版本和有效人数锁定比例，每笔订单独立计算，确认后的比例保持不变。
  6. 积分状态：已到账、待释放或未发放
    新订单的奖励先显示为待释放，满7天按有效实付整笔到账后即可使用。钱包已到账积分总额为通用积分与GPT系列专项积分可用余额之和，待释放单独展示；历史通用奖励计入通用积分。邀请页累计已到账奖励含历史已使用部分。未发放仅为奖励资格，不计入积分总额、待释放或可用余额；历史订单沿用原条件。
  7. 有效实付：不包含赠送与奖励
    邀请奖励按有效现金实付核算，年付优惠积分、自动续费赠送和邀请奖励本身不重复产生邀请奖励。
  8. 退款影响：未释放奖励按比例取消
    部分退款按有效实付比例取消对应未释放奖励；全额退款取消该订单未释放奖励。已有奖励到账的订单退款及冲回由客服核实。
  9. 活动调整：既有订单不追改
    活动比例调整只影响之后支付的新订单；已有待释放及已到账奖励均不追改，活动结束不清空已锁定奖励。历史规则订单继续按原规则处理。
  10. 奖励用途：GPT系列模型调用
    邀请奖励可用于GPT系列模型调用，为模型调用积分，不支持提现、转出或兑换现金；依法申请退款的权益不受影响。本人订阅、自邀及异常交易不参与邀请奖励。
